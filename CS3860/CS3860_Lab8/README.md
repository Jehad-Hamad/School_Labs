# CS3860 Lab 8 - Prolog Text Adventure Game

A simple text-based adventure game written in Prolog. You play as a 4-year-old boy searching for your security blanket (blankie) in a house with interconnected rooms.

## How to Run

```bash
swipl main.plg
```

Then at the Prolog prompt:

```prolog
?- goto(office).
?- goto(hall).
?- look.
```
